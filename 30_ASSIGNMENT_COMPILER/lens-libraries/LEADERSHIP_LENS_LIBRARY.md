# Leadership Lens Library

## Purpose

This library gives the instructor simple ways to embed leadership practice into technical assignments.

Leadership is treated as responsibility, communication, initiative, steadiness, and care for shared work.

## Use Rule

Leadership prompts should be practical and observable.

They should fit naturally inside the assignment.

## Leadership Lens Patterns

| Lens | Best Used For | Student Prompt |
|---|---|---|
| Role Clarity | Team tasks | Identify who is responsible for setup, checking, documenting, and cleanup. |
| Peer Explanation | Theory and code work | Explain your reasoning to a partner before submitting. |
| Quality Check Partner | Lab work | Ask a partner to check one measurement, connection, label, or decision. |
| Calm Problem Response | Troubleshooting | Describe the issue clearly and identify the next step. |
| Initiative Check | Independent work | Identify one useful action you can take without waiting. |
| Shared Workspace Care | Lab and shop work | Leave the work area organized, safe, and ready for the next user. |
| Communication Before Action | Sequenced tasks | State the plan before acting. |
| Accountability Statement | Reflection | Name one decision you made and one result of that decision. |
| Handoff Readiness | Multi-step work | Prepare your work so another person could understand what was done. |

## Starter Prompts

- What role did you take in this task?
- How did you help the work move forward?
- What did you communicate before acting?
- What did you check for someone else?
- What did someone else check for you?
- What did you do to leave the work ready for the next person?

## Instructor Notes

For individual assignments, use accountability, initiative, or peer explanation.

For lab assignments, use role clarity, quality check partner, and shared workspace care.

For troubleshooting, use calm problem response and communication before action.

For multi-day work, use handoff readiness and documentation habits.
