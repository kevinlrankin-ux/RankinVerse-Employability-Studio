# Safety Lens Library

## Purpose

The safety lens library gives the instructor reusable safety habits that can be embedded into assignments across the Electrical Trades program.

Safety should not live only inside OSHA-10hr.

Safety should appear inside DC Theory, Conduit Bending, Wire Applications, Print Reading, Code and Practices, Studio 5000 / Emulate 3D, and every lab or classroom routine where safety thinking belongs.

## Use Rule

A safety lens should be short, practical, and connected to the actual task.

It should not feel like an extra worksheet stapled onto the assignment.

## Safety Lens Patterns

| Lens | Best Used For | Student Prompt |
|---|---|---|
| Pre-Task Hazard Prediction | Any lab or hands-on task | Before beginning, identify one thing that could go wrong and the action that prevents it. |
| Tool Readiness Check | Tool-based assignments | Check that the correct tool is selected, inspected, and used for the correct purpose. |
| Material Condition Check | Wire, conduit, devices, equipment | Inspect materials for damage, incorrect size, missing parts, or improper condition before use. |
| PPE Awareness | Lab and shop work | Identify what protective equipment or safe work condition applies before starting. |
| Stop-and-Ask Trigger | Unclear or risky tasks | Name one situation where you should pause and ask before continuing. |
| Work Area Awareness | Labs, bending, wiring, installation practice | Identify one work-area condition that could affect safety or quality. |
| Procedure First | Code, OSHA, lab procedures | State the required procedure before performing the task. |
| Energy Awareness | DC Theory, AC Theory, motors, controls | Identify whether the task involves a source of electrical energy, stored energy, or simulated energy. |
| Verification Before Action | Wiring, troubleshooting, controls | Verify the condition before making a change or assuming the result. |
| Housekeeping as Safety | Shop or lab routines | Clear the work area, organize materials, and remove trip or clutter hazards. |

## Starter Safety Checks

- What is the most likely mistake in this task?
- What should be checked before beginning?
- What tool or material condition matters most?
- What should be verified before power, testing, or evaluation?
- What step should not be rushed?
- What would make this task unsafe or low-quality?

## Instructor Notes

The safety lens should match the task type.

For theory work, use energy awareness, verification, or procedure-first prompts.

For lab work, use hazard prediction, tool readiness, material condition, and work-area awareness.

For code work, use procedure-first and verification prompts.

For controls and simulation, use sequencing, verification, and energy-awareness prompts.
