# Executive-Function Lens Library

## Purpose

This library gives the instructor reusable ways to embed planning, sequencing, attention, organization, and self-checking into Electrical Trades assignments.

Executive-function support should feel like part of the work, not a separate lesson.

## Use Rule

Use one small scaffold at a time.

The scaffold should help students start, sequence, monitor, or finish the task.

## Lens Patterns

| Lens | Best Used For | Student Prompt |
|---|---|---|
| Start Plan | Any assignment | Before starting, list the first three steps. |
| Time Estimate | Labs and longer tasks | Estimate how long the task will take, then compare with the actual time. |
| Materials Check | Lab and shop work | List or confirm the tools and materials needed before starting. |
| Sequence Check | Multi-step work | Put the task steps in order before beginning. |
| Stop Point | Complex tasks | Identify one point where you should pause and check your work. |
| Error Prediction | Theory, lab, code, and troubleshooting | Predict one common mistake and how to avoid it. |
| Completion Check | Any assignment | Before submitting, check your work against the criteria. |
| Reset Plan | Troubleshooting or revision | If the work is not correct, identify the next small correction step. |
| Evidence Check | Code, print reading, troubleshooting | Point to the evidence that supports your answer or decision. |
| Reflection Loop | End of assignment | Name what worked, what changed, and what you would do next time. |

## Starter Prompts

- What is the first step?
- What materials are needed?
- What order should the steps happen in?
- Where should you pause and check?
- What mistake is most likely?
- What evidence supports your answer?
- How do you know the work is complete?

## Instructor Notes

For hands-on work, use start plan, materials check, sequence check, and completion check.

For theory work, use evidence check, error prediction, and reflection loop.

For troubleshooting, use reset plan, stop point, and evidence check.
