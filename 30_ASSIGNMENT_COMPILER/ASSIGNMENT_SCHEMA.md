# Assignment Schema

## Purpose

This schema defines the minimum information needed for a teacher-reviewed Electrical Trades assignment.

The goal is to keep assignments consistent across courses while still allowing each course to feel different.

## Required Fields

| Field | Purpose |
|---|---|
| Assignment Title | Names the assignment in plain language. |
| Course | Identifies the course connected to the assignment. |
| Unit or Topic | Places the assignment inside a course sequence. |
| Technical Skill | Names the trade skill, concept, or practice being developed. |
| Student Task | Explains what students will do. |
| Materials and Tools | Lists required tools, materials, documents, or software. |
| Safety Lens | Adds a safety habit, check, or expectation. |
| Leadership Lens | Adds a workplace behavior or responsibility practice. |
| Executive-Function Scaffold | Adds planning, sequencing, time management, or self-check support. |
| Documentation Habit | Defines what students record, label, explain, or submit. |
| Reflection Prompt | Gives students a short self-check or meaning-making prompt. |
| Rubric Criteria | Defines what the teacher will look for when reviewing work. |
| Teacher Review Status | Shows whether the assignment is draft, reviewed, ready, or needs revision. |

## Review Status Values

- draft
- needs review
- reviewed
- ready for classroom use
- used in class
- needs revision
- archived

## Current Boundary

The assignment compiler supports the instructor.

Generated materials are drafts until reviewed by the teacher.

## Quality Test

A good assignment should answer:

- What skill is being practiced?
- What safety habit is being reinforced?
- What leadership behavior is being practiced?
- What planning or self-management support is included?
- What must students document?
- How will the teacher know the work is acceptable?
