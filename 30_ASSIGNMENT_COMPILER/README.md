# Assignment Compiler

The Assignment Compiler is the first core engine of the Electrical Trades Program Operating System.

Its job is to help the instructor turn a technical task into a complete assignment package.

The compiler should support:

- technical skill development
- safety awareness
- leadership practice
- executive-function support
- documentation habits
- reflection
- rubric drafting
- teacher review

The compiler is instructor-facing for the current build.

Generated materials are drafts until reviewed.

The first proof course is Conduit Bending.

The second proof course is DC Theory.
