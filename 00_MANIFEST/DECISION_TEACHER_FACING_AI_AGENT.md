# Decision: Teacher-Facing AI Agent Boundary

## Decision

The AI agent for RankinVerse Employability Studio will be teacher-facing only for the current build.

It is not a learner-facing chatbot, tutor, companion, or automated decision-maker.

The agent exists to help the instructor design, organize, improve, and operate the instructional system behind the classroom.

## Purpose

The agent should reduce repetitive teacher workflow while improving the quality and consistency of the Electrical Trades program.

It may help with:

- assignment drafting
- rubric drafting
- safety checks
- leadership skill prompts
- executive-function scaffolds
- reflection prompts
- module organization
- Google Workspace asset preparation
- progress-structure planning
- teacher review workflows

## Long Game

The long game is to grow this project from a course platform into a complete Electrical Trades program operating system.

That operating system should support:

- curriculum
- assignments
- safety routines
- employability skills
- leadership development
- executive-function supports
- classroom workflow
- Google Workspace materials
- program documentation
- career-readiness pathways

The AI layer is only one part of the system. The core is the instructional operating model.

## Guardrail

The teacher remains the decision-maker.

Generated materials should be reviewed before use.

The system should strengthen professional judgment, not replace it.

## Working Principle

The platform may be chosen by the institution, but the instructional grammar belongs to the program.

Every assignment should be able to carry technical skill, safety awareness, leadership practice, self-management, and workplace readiness at the same time.

## Status

Locked for the current build direction.

Any future learner-facing AI feature requires a separate decision record and explicit review.
