# Source Registry Template

## Purpose

The Source Registry is the clean catalog of reviewed materials that may support the Electrical Trades Program OS.

It is not the raw document folder.

It is the reviewed index that tells the product layer what sources exist, what they are for, and whether they can be used.

## Registry Rule

A source should not be used by the product OS until it has a registry entry.

## Registry Columns

| Column | Purpose |
|---|---|
| Source ID | Unique identifier. |
| Title | Plain-language title. |
| Source Type | Course material, policy, requisition, advisory, recruiting, assessment, or other. |
| Related Course | Course or program area connected to the source. |
| Summary | Short description of what the source contains. |
| Source Status | Raw, reviewed, approved, needs cleanup, do not use. |
| Use Level | Public-safe, internal, restricted, unknown. |
| Approved Uses | Assignment support, policy reference, recruiting, advisory summary, requisition planning, archive only. |
| Tags | Search and grouping tags. |
| Reviewer | Person who reviewed the source. |
| Last Reviewed | Date reviewed. |
| Notes | Short review or usage notes. |

## First Registry Categories

- Course content
- Safety and compliance
- Program policy
- Requisitions and materials
- Advisory committee materials
- Recruiting materials
- Employer-facing materials
- Career-readiness materials

## Dashboard Use

The teacher dashboard may eventually show:

- sources available by course
- sources needing review
- sources approved for assignment support
- sources not ready for product use
- missing sources for planned modules

## End-User Test

The instructor should be able to look at the registry and know which materials are ready to support the OS.
