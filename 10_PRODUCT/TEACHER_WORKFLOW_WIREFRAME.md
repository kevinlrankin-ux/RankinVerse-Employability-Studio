# Teacher Workflow Wireframe

## Purpose

This document describes the first end-user workflow for the Electrical Trades Program OS.

The goal is to make the system visible from the instructor perspective before building deeper automation.

## Primary Workflow

Build and review an assignment.

## User

Instructor.

## Workflow Summary

```text
Open Dashboard
-> Select Course
-> Select Unit or Topic
-> Start Assignment Builder
-> Add Technical Skill
-> Apply Safety Lens
-> Apply Leadership Lens
-> Apply Executive-Function Lens
-> Generate Draft Assignment
-> Review Draft
-> Mark Ready or Send Back for Revision
-> Record in Program Tracker
```

## Step 1: Open Dashboard

Instructor sees:

- program overview
- course spine
- assignment builder button
- review queue
- next build action
- governance status area

Teacher question answered:

Where do I start?

## Step 2: Select Course

Instructor selects one course:

- DC Theory
- Conduit Bending
- Wire Applications
- Code and Practices
- OSHA-10hr
- Print Reading
- Studio 5000 / Emulate 3D

Teacher question answered:

Which course am I building for?

## Step 3: Select Unit or Topic

Instructor chooses or types the topic.

Examples:

- Basic 90-Degree Bend
- Ohm's Law Relationship
- Reading a Simple Floor Plan
- Wire Termination Practice
- PPE and Hazard Recognition

Teacher question answered:

What part of the course is this connected to?

## Step 4: Define Technical Skill

Instructor enters the trade skill, concept, or practice.

Teacher question answered:

What should students actually get better at?

## Step 5: Apply Safety Lens

Instructor selects or accepts one safety lens.

Examples:

- pre-task hazard prediction
- tool readiness check
- energy awareness
- verification before action
- work area awareness

Teacher question answered:

Where does safety show up inside this assignment?

## Step 6: Apply Leadership Lens

Instructor selects or accepts one leadership lens.

Examples:

- role clarity
- peer explanation
- quality check partner
- calm problem response
- handoff readiness

Teacher question answered:

Where does leadership show up inside the work?

## Step 7: Apply Executive-Function Lens

Instructor selects or accepts one executive-function scaffold.

Examples:

- start plan
- time estimate
- materials check
- sequence check
- completion check
- evidence check

Teacher question answered:

How does the assignment help students plan, monitor, or complete the task?

## Step 8: Generate Draft Assignment

The system produces a draft assignment structure.

Draft may include:

- student task
- tools and materials
- safety prompt
- leadership prompt
- planning prompt
- documentation habit
- rubric criteria
- reflection prompt
- teacher notes

Teacher question answered:

What did the system produce?

## Step 9: Review Draft

Instructor reviews and edits the draft.

Review choices:

- approve
- revise
- duplicate
- archive
- hold for later

Teacher question answered:

Is this good enough for my classroom?

## Step 10: Mark Ready and Track

When approved, the assignment is marked ready for classroom use and added to the tracker.

Teacher question answered:

What is ready, and where is it recorded?

## Minimum Clickable Prototype

The first clickable or semi-clickable version should include:

1. dashboard page
2. course selector
3. assignment builder form
4. draft output page
5. review status control
6. tracker entry

## End-User Test

The instructor should be able to move through the workflow using a sample task and produce a draft assignment without needing technical explanation.

## Quality Rule

The workflow is successful only if it feels like it saves teacher effort while preserving teacher control.
