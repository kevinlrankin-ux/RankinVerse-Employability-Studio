# Course Sequence Map

## Purpose

This document begins organizing the Electrical Trades Program OS by instructional sequence.

The goal is to help the instructor see how courses, units, assignments, safety habits, leadership practice, and executive-function supports can build over time.

This is not a final pacing guide.

It is the first sequencing layer for the operating system.

## Sequence Principle

Start with foundations.

Then move toward application, interpretation, standards, safety, and automation.

Students should experience the program as connected growth, not disconnected classes.

## Suggested Early Program Flow

| Sequence | Course Area | Instructional Focus | Why It Comes Here |
|---|---|---|---|
| 1 | OSHA-10hr | Safety language, hazard recognition, reporting, worker rights | Establishes safety grammar for the whole program. |
| 2 | DC Theory | Voltage, current, resistance, measurement, circuit reasoning | Builds foundational electrical reasoning. |
| 3 | Print Reading | Symbols, location, evidence, translating documents into plans | Builds document literacy before field-style tasks expand. |
| 4 | Conduit Bending | Measurement, layout, sequencing, tool use, visible workmanship | Converts planning and measurement into physical practice. |
| 5 | Wire Applications | Conductor preparation, terminations, circuit construction, workmanship | Builds applied installation habits. |
| 6 | Code and Practices | Evidence-based standards, professional reasoning, inspection thinking | Connects classroom choices to formal expectations. |
| 7 | Studio 5000 / Emulate 3D | I/O, sequence, simulation, troubleshooting, controls | Extends trade thinking into modern automation. |

## First Vertical Sequence

A first mini-sequence for testing the OS could be:

1. OSHA-10hr: Hazard Recognition and Reporting Basics
2. DC Theory: Ohm's Law Relationship and Circuit Reasoning
3. Print Reading: Identifying Symbols and Locating Electrical Information
4. Conduit Bending: Basic 90-Degree Bend Layout and Execution
5. Wire Applications: Basic Conductor Preparation and Termination Practice
6. Code and Practices: Basic Code Lookup and Evidence-Based Answer
7. Studio 5000 / Emulate 3D: Basic I/O Identification and Sequence Explanation

## Cross-Course Thread

Each course should reinforce the same formation pattern:

- technical skill
- safety awareness
- leadership practice
- executive-function support
- documentation habit
- reflection

## Example Progression of Student Habits

| Habit | Early Expression | Later Expression |
|---|---|---|
| Safety Awareness | Identify a hazard in a scenario | Predict and prevent risks during lab or automation work |
| Evidence Use | Point to a print or reference | Justify decisions using code, prints, measurements, or simulation behavior |
| Planning | List first three steps | Create a sequence before physical or controls work |
| Communication | Explain reasoning to a partner | Communicate a work plan or troubleshooting path clearly |
| Documentation | Record a result | Produce work that another person can inspect, understand, and continue |
| Leadership | Complete a role responsibly | Support shared safety, quality, and handoff readiness |

## Dashboard Use

The dashboard should eventually show:

- current course sequence
- current assignment sequence
- missing assignments by course
- skills already introduced
- habits already reinforced
- next recommended assignment

## End-User Test

The instructor should be able to look at this map and decide:

- Does this sequence reflect a reasonable learning path?
- What would need to move earlier or later?
- Which course needs more foundation before use?
- Which assignment should be built next?
