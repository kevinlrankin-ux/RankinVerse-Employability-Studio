# Course Index

## Purpose

The Course Index gives the teacher dashboard a clean list of courses, patched-in fundamentals, and first-build priorities.

This is the dashboard-facing version of the Electrical Trades program spine.

## Core Courses

| Course ID | Course Title | Type | First-Build Priority | Notes |
|---|---|---|---|---|
| DC_THEORY | DC Theory | Theory | High | Foundational electrical reasoning, measurement, relationships, and troubleshooting logic. |
| CONDUIT_BENDING | Conduit Bending | Lab | High | Physical layout, measurement discipline, sequencing, tool use, and workmanship. |
| WIRE_APPLICATIONS | Wire Applications | Lab | Medium | Installation practice, conductor handling, terminations, neatness, and procedural accuracy. |
| CODE_PRACTICES | Code and Practices | Code / Standards | Medium | Connects classroom decisions to electrical standards and inspection thinking. |
| OSHA_10 | OSHA-10hr | Safety / Compliance | Medium | Safety language, hazard recognition, worker rights, reporting, and safe work conduct. |
| PRINT_READING | Print Reading | Print / Interpretation | Medium | Symbol literacy, spatial reasoning, planning from drawings, and translating documents into work. |
| STUDIO_5000_EMULATE_3D | Studio 5000 / Emulate 3D | Controls / Automation | Medium | PLC logic, sequencing, simulation thinking, troubleshooting, and industrial awareness. |

## Patched-In Fundamentals

| Fundamental ID | Title | How It Should Appear |
|---|---|---|
| LEADERSHIP | Leadership | Embedded through role clarity, communication, initiative, quality checks, and responsibility. |
| MOTORS | Motors | Patched into circuits, controls, troubleshooting, automation, and equipment behavior. |
| AC_THEORY | AC Theory | Patched as students move from DC foundations toward real-world power systems and controls. |

## First Proof Courses

The first two proof courses are:

1. Conduit Bending
2. DC Theory

These prove that the operating system can support both lab-based and theory-based instruction.

## Dashboard Use

The dashboard should use this index to populate:

- course selector
- course cards
- assignment builder course dropdown
- tracker course filters
- build-priority views
- course slice status indicators

## Course Card Pattern

Each course card should eventually show:

- course title
- course type
- active assignments
- draft assignments
- ready assignments
- missing safety lens count
- missing leadership lens count
- missing executive-function lens count
- next recommended build action

## End-User Test

The instructor should be able to open the course index and immediately recognize the program as their actual Electrical Trades classroom, not a generic LMS structure.
