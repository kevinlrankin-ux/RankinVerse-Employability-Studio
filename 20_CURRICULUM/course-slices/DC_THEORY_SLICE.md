# DC Theory Vertical Slice

## Purpose

This is the second course-specific proof slice for the Electrical Trades Program OS.

The goal is to show that the assignment compiler works for theory-based instruction, not only hands-on lab work.

## Course

DC Theory

## Course Role

DC Theory builds the foundation for electrical reasoning, measurement, resistance, current, voltage, power, circuit relationships, and troubleshooting logic.

## Why This Course Second

DC Theory tests whether the OS can support:

- abstract reasoning
- calculations
- evidence-based explanations
- meter-use awareness
- troubleshooting logic
- student self-checking
- peer explanation

## Starter Unit

Ohm's Law Relationship and Circuit Reasoning

## Technical Skill

Students use voltage, current, and resistance relationships to solve a basic DC circuit problem and explain the reasoning behind the answer.

## Student Task

Students will analyze a simple DC circuit scenario, identify the known values, select the correct relationship, solve for the missing value, and explain how they know the answer is reasonable.

## Materials and Tools

- assignment sheet
- calculator
- pencil or digital workspace
- formula reference if allowed
- sample circuit values
- teacher-approved example problem

## Safety Lens

Energy awareness and verification before action.

Student prompt:

Even when working on paper or simulation, identify what would need to be verified before this became a real circuit. Name one condition that should never be assumed in the field.

## Leadership Lens

Peer explanation.

Student prompt:

Before submitting, explain your reasoning to a partner. Your explanation should include what you knew, what you solved for, and why the answer makes sense.

## Executive-Function Scaffold

Evidence check and error prediction.

Student prompt:

Before solving, list the known values and the missing value. Predict one common mistake someone might make in this problem and how to avoid it.

## Documentation Habit

Students record:

- known values
- missing value
- selected relationship
- calculation steps
- final answer with unit
- reasonableness check
- one common error to avoid

## Rubric Criteria

| Criteria | Evidence of Success |
|---|---|
| Setup | Student identifies known and missing values. |
| Relationship | Student selects an appropriate electrical relationship. |
| Calculation | Student shows clear steps and correct units. |
| Reasoning | Student explains why the answer is reasonable. |
| Safety awareness | Student connects paper/simulation work to real-world verification. |
| Peer explanation | Student can explain the reasoning to another person. |
| Documentation | Work is organized enough for the teacher to follow. |

## Reflection Prompt

What part of the problem helped you know which relationship to use? What mistake would you watch for next time?

## Teacher Notes

Possible common errors:

- mixing up voltage, current, and resistance
- using the wrong unit
- writing only the answer without showing reasoning
- skipping the known/missing setup
- treating a calculated answer as automatically safe in the real world

Possible teacher reminders:

- identify what is known first
- write the unit with the value
- explain the answer, not just calculate it
- connect theory back to field verification
