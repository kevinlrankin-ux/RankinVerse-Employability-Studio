# Print Reading Vertical Slice

## Purpose

This is a course-specific proof slice for Print Reading.

The goal is to show how the Electrical Trades Program OS supports symbolic literacy, spatial reasoning, planning from documents, and translating a drawing into work.

## Course

Print Reading

## Course Role

Print Reading builds symbolic literacy, spatial reasoning, interpretation, planning from documents, and the ability to translate drawings into work.

## Why This Course Matters

Print Reading helps students learn how to slow down, interpret information, locate details, and plan work from a document before acting.

This course helps the OS support:

- symbol recognition
- plan navigation
- evidence-based answers
- location tracking
- scope awareness
- documentation habits
- communication before action

## Starter Unit

Identifying Symbols and Locating Electrical Information on a Print

## Technical Skill

Students identify selected electrical symbols, locate them on a drawing, and explain what information the print gives them before work begins.

## Student Task

Students will review a simple electrical print or excerpt, identify assigned symbols, locate related information, and write a short work-planning explanation.

## Materials and Tools

- simple electrical print or excerpt
- symbol legend if provided
- highlighter or markup tool
- assignment sheet
- pencil or digital annotation tool

## Safety Lens

Procedure first and verification before action.

Student prompt:

Before assuming what work should be done, identify where the print gives evidence for your answer. Name one thing that would need to be verified before field work begins.

## Leadership Lens

Communication before action.

Student prompt:

Explain your plan interpretation to a partner before moving forward. State what symbol you found, where it is located, and what it tells you.

## Executive-Function Scaffold

Evidence check.

Student prompt:

For each answer, point to the evidence on the print that supports your interpretation.

## Documentation Habit

Students record:

- symbol identified
- location on print
- meaning or purpose
- evidence used
- one question or verification needed before work

## Rubric Criteria

| Criteria | Evidence of Success |
|---|---|
| Symbol Identification | Student correctly identifies assigned symbols. |
| Location Accuracy | Student locates symbols or information on the print. |
| Evidence Use | Student points to print evidence that supports the answer. |
| Planning Explanation | Student explains what the print indicates before action. |
| Communication | Student explains interpretation clearly to another person. |
| Documentation | Student records symbols, locations, evidence, and verification needs. |

## Reflection Prompt

What detail on the print was easiest to miss? What will you check first next time you read a drawing?

## Teacher Notes

Possible common errors:

- guessing from memory instead of reading the print
- ignoring the legend or notes
- confusing similar symbols
- missing location references
- acting before verifying scope or details

Teacher reminders:

- students should show evidence
- interpretation should come before action
- prints are communication tools
- unclear information should become a question, not an assumption
