# Code and Practices Vertical Slice

## Purpose

This is a course-specific proof slice for Code and Practices.

The goal is to show how the Electrical Trades Program OS supports code lookup, evidence-based decisions, professional reasoning, and documentation.

## Course

Code and Practices

## Course Role

Code and Practices connects classroom decisions to electrical standards, trade expectations, inspection thinking, and professional reasoning.

## Why This Course Matters

Code work helps students learn that professional decisions should be supported by evidence, not guesses.

This course helps the OS support:

- code navigation
- evidence-based answers
- professional judgment
- documentation
- inspection thinking
- communication before action
- respectful uncertainty when more information is needed

## Starter Unit

Basic Code Lookup and Evidence-Based Answer

## Technical Skill

Students locate a relevant code reference or practice standard, explain what it means in plain language, and apply it to a simple classroom scenario.

## Student Task

Students will review a teacher-provided scenario, locate the relevant reference, identify the key requirement or expectation, and explain the answer with evidence.

## Materials and Tools

- code book or approved reference material
- teacher-provided scenario
- assignment sheet
- pencil or digital workspace
- highlighter or note tool

## Safety Lens

Procedure first.

Student prompt:

Before answering from memory, identify the reference or procedure that supports your decision. Explain why guessing is not enough for this task.

## Leadership Lens

Evidence-based communication.

Student prompt:

Explain your answer to a partner using the reference, not only your opinion. Be clear about what the source says and what you still need to verify.

## Executive-Function Scaffold

Evidence check.

Student prompt:

Record where you found the answer, what the key language means, and how it applies to the scenario.

## Documentation Habit

Students record:

- scenario summary
- reference location
- key requirement or expectation
- plain-language explanation
- application to the scenario
- one question or uncertainty that remains

## Rubric Criteria

| Criteria | Evidence of Success |
|---|---|
| Reference Location | Student identifies a relevant reference. |
| Evidence Use | Student uses the reference to support the answer. |
| Plain-Language Explanation | Student explains the meaning clearly. |
| Application | Student applies the reference to the scenario. |
| Professional Reasoning | Student avoids unsupported guessing. |
| Documentation | Student records reference, explanation, and uncertainty clearly. |

## Reflection Prompt

What made this reference easy or difficult to use? What would you do if you were unsure in the field?

## Teacher Notes

Possible common errors:

- answering from memory only
- using a reference without explaining it
- copying language without understanding it
- ignoring scenario details
- treating uncertainty as failure instead of a reason to verify

Teacher reminders:

- code work is evidence work
- students should learn how to explain the reference
- uncertainty should become a verification step
- professional practice requires documentation and judgment
