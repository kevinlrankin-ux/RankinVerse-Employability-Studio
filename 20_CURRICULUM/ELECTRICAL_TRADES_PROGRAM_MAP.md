# Electrical Trades Program Map

## Purpose

This document defines the course spine for the long-term Electrical Trades program operating system.

The teacher-facing AI agent should use this map to understand the major instructional areas of the program and to help generate assignments, rubrics, safety checks, leadership prompts, executive-function scaffolds, and Google Workspace materials that fit the actual classroom.

## Core Courses

The program currently includes the following courses:

1. DC Theory
2. Conduit Bending
3. Wire Applications
4. Code and Practices
5. OSHA-10hr
6. Print Reading
7. Studio 5000 / Emulate 3D

## Patched-In Fundamentals

The following fundamentals should be embedded across the program rather than treated only as isolated standalone units:

1. Leadership
2. Motors
3. AC Theory

## Operating-System View

The program should not be treated as a loose collection of classes.

The long-term direction is to organize these courses into a complete Electrical Trades program operating system.

That system should help manage:

- curriculum planning
- assignment creation
- safety routines
- lab readiness
- tool and material expectations
- student progress structures
- employability skill development
- leadership practice
- executive-function supports
- documentation habits
- Google Workspace assets
- career-readiness pathways

## Cross-Course Lenses

Every course should be able to carry more than technical content.

Whenever possible, assignments should include:

- technical skill
- safety awareness
- leadership practice
- executive-function scaffold
- workplace communication
- documentation habit
- reflection or self-check

## Course Role Notes

### DC Theory

Builds the foundation for electrical reasoning, measurement, resistance, current, voltage, power, circuits, and troubleshooting logic.

### Conduit Bending

Builds physical layout skill, measurement discipline, planning, sequencing, accuracy, tool use, and pride in visible workmanship.

### Wire Applications

Builds applied installation skill, conductor handling, termination practice, circuit construction, neatness, safety, and procedural accuracy.

### Code and Practices

Connects classroom decisions to electrical standards, trade expectations, inspection thinking, and professional reasoning.

### OSHA-10hr

Establishes baseline safety language, hazard recognition, worker rights, employer responsibilities, reporting expectations, and safe work conduct.

### Print Reading

Builds symbolic literacy, spatial reasoning, interpretation, planning from documents, and the ability to translate drawings into work.

### Studio 5000 / Emulate 3D

Builds automation literacy, PLC logic, simulation thinking, sequencing, controls reasoning, troubleshooting, and modern industrial awareness.

## Fundamental Patch Notes

### Leadership

Leadership should be taught as responsibility, steadiness, communication, role clarity, initiative, and care for the shared work environment.

Leadership should appear inside assignments through team roles, peer checks, communication prompts, planning responsibilities, and reflection.

### Motors

Motors should be patched into the program wherever they strengthen applied understanding of circuits, controls, troubleshooting, automation, and equipment behavior.

### AC Theory

AC Theory should be patched into the program as students move from DC foundations toward real-world power systems, motors, controls, and code-related reasoning.

## Teacher-Facing Agent Use

The agent should use this course map to support the teacher by generating materials that are aligned to the program structure.

The agent may help create:

- course modules
- daily assignments
- lab sheets
- rubrics
- safety pre-checks
- material lists
- reflection prompts
- leadership prompts
- executive-function scaffolds
- review activities
- assessment outlines
- Google Docs, Slides, Forms, and Sheets structures

The agent remains teacher-facing only.

Generated materials should support teacher review and program operation, not replace teacher judgment.

## Working Principle

The long game is not only to automate classroom tasks.

The long game is to build a coherent Electrical Trades program operating system that helps students practice technical skill, safety, leadership, self-management, documentation, and workplace readiness through the regular rhythm of the classroom.
