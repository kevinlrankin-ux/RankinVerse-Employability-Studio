# Cross-Course Integration Matrix

## Purpose

This matrix shows how the Electrical Trades Program OS should weave patched-in fundamentals across the core courses.

The patched-in fundamentals are:

- Leadership
- Motors
- AC Theory

These should not exist only as separate units.

They should appear where they naturally strengthen technical skill, safety, reasoning, documentation, and workplace readiness.

## Integration Principle

Patch fundamentals into real assignments.

Do not add them as disconnected side lessons unless a standalone lesson is truly needed.

## Matrix

| Course | Leadership Integration | Motors Integration | AC Theory Integration |
|---|---|---|---|
| DC Theory | Peer explanation, accountability, evidence-based reasoning | Introduce motor behavior only as a future application of electrical relationships | Bridge later from DC relationships to changing current, waveforms, and real-world power systems |
| Conduit Bending | Role clarity, quality check partner, shared workspace care | Connect conduit planning to motor circuits or equipment feeds when appropriate | Connect pathway planning to future AC power distribution contexts |
| Wire Applications | Handoff readiness, neatness as professionalism, partner quality checks | Use motor-related terminations or control-circuit preparation when appropriate | Connect conductor work to AC circuits, branch circuits, and equipment connections |
| Code and Practices | Professional judgment, evidence-based decisions, communication before action | Use code lookup examples related to motors when appropriate | Use AC system examples where code interpretation requires it |
| OSHA-10hr | Responsibility, reporting, stop-and-ask habits, care for shared safety | Use motor and machinery hazards when appropriate | Use electrical hazard examples connected to AC systems |
| Print Reading | Communication before action, evidence check, shared interpretation | Locate motor symbols, equipment schedules, and control references | Interpret AC power distribution symbols and notes where appropriate |
| Studio 5000 / Emulate 3D | Calm problem response, handoff readiness, troubleshooting communication | Strong connection to motor control, sequencing, inputs, outputs, and automation | Connect control logic to AC motor systems and industrial contexts |

## Integration by Assignment Type

| Assignment Type | Best Leadership Patch | Best Motors Patch | Best AC Theory Patch |
|---|---|---|---|
| Lab task | Role clarity, quality check, workspace care | Equipment connection, motor circuit context | Power system or load context |
| Theory task | Peer explanation, evidence check | Motor behavior as application | AC comparison or future bridge |
| Print reading | Communication before action | Motor symbols and schedules | AC power distribution symbols |
| Code task | Evidence-based decision | Motor code lookup where appropriate | AC circuit rule context |
| Troubleshooting | Calm problem response | Motor control logic | AC fault or measurement context |
| Reflection | Accountability statement | Where motor knowledge would matter | Where AC theory changes the decision |

## Dashboard Use

The dashboard should eventually show whether assignments include:

- leadership lens
- motor connection
- AC theory connection

This can help the teacher see whether fundamentals are being woven through the program.

## End-User Test

The instructor should be able to look at this matrix and decide:

- where leadership naturally belongs
- where motors naturally belong
- where AC Theory naturally belongs
- which courses need more integration
- which assignments are already carrying more than technical content
