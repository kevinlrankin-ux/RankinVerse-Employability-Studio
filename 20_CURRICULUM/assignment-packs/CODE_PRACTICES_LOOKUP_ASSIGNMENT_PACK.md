## Technical Skill

Students locate a relevant reference, explain it in plain language, and apply it to a classroom scenario.

## Student Task

Students will:

1. Read a teacher-provided scenario.
2. Identify the question that needs to be answered.
3. Locate a relevant reference.
4. Record where the reference is located.
5. Explain the reference in plain language.
6. Apply it to the scenario.
7. Identify one thing that should be verified before field work.

## Materials and Tools

- approved reference material
- teacher-provided scenario
- assignment sheet
- pencil or digital workspace
- note or highlight tool

## Safety Lens

Procedure first.

Students should use the reference before answering from memory.

## Leadership Lens

Evidence-based communication.

Students explain their answer to a partner using the reference.

## Executive-Function Scaffold

Evidence check.

Students record where the answer came from and how it applies.

## Documentation Habit

Students record:

- scenario summary
- reference location
- plain-language meaning
- application to the scenario
- one remaining question or verification step

## Rubric

| Criteria | Evidence of Success |
|---|---|
| Reference Location | Student identifies a relevant reference. |
| Evidence Use | Student uses the reference to support the answer. |
| Explanation | Student explains the meaning clearly. |
| Application | Student applies the reference to the scenario. |
| Documentation | Student records the answer path clearly. |

## Reflection Prompt

What helped you find the answer? What would you do if the reference was unclear?

## Teacher Notes

Watch for unsupported guessing, copying without understanding, and skipping the explanation step.
