## Technical Skill

Students will identify selected electrical symbols, locate them on a drawing, and explain what information the print gives them before work begins.

## Student Task

You will review a simple electrical print or excerpt.

You will:

1. Identify assigned electrical symbols.
2. Locate the symbols on the print.
3. Use the print, legend, notes, or labels as evidence.
4. Explain what the print tells you.
5. Identify one question or verification needed before field work begins.

## Materials and Tools

- simple electrical print or excerpt
- symbol legend if provided
- highlighter or markup tool
- assignment sheet
- pencil or digital annotation tool

## Safety Lens

Procedure first and verification before action.

Before assuming what work should be done, identify where the print gives evidence for your answer.

Name one thing that would need to be verified before field work begins.

## Leadership Lens

Communication before action.

Explain your interpretation to a partner before moving forward.

State what symbol you found, where it is located, and what it tells you.

## Executive-Function Scaffold

Evidence check.

For each answer, point to the evidence on the print that supports your interpretation.

## Documentation Habit

Record the following:

- symbol identified
- location on print
- meaning or purpose
- evidence used
- one question or verification needed before work

## Rubric

| Criteria | Evidence of Success |
|---|---|
| Symbol Identification | Student correctly identifies assigned symbols. |
| Location Accuracy | Student locates symbols or information on the print. |
| Evidence Use | Student points to print evidence that supports the answer. |
| Planning Explanation | Student explains what the print indicates before action. |
| Communication | Student explains interpretation clearly to another person. |
| Documentation | Student records symbols, locations, evidence, and verification needs. |

## Reflection Prompt

What detail on the print was easiest to miss?

What will you check first next time you read a drawing?

## Teacher Notes

Common errors to watch for:

- guessing from memory instead of reading the print
- ignoring the legend or notes
- confusing similar symbols
- missing location references
- acting before verifying scope or details

Teacher reminders:

- students should show evidence
- interpretation should come before action
- prints are communication tools
- unclear information should become a question, not an assumption
