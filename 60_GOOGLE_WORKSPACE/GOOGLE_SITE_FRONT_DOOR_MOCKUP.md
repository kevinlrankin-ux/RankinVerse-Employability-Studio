# Google Site Front-Door Mockup

## Purpose

This document defines the first Google Site front-door concept for the Electrical Trades Program OS.

The site should be a clean instructor entry point.

It should point to the dashboard, courses, assignment builder, review queue, tracker, source registry, and build status.

## Primary User

Instructor.

## Site Name

Electrical Trades Program OS

## Recommended Navigation

1. Home
2. Teacher Dashboard
3. Course Spine
4. Assignment Builder
5. Review Queue
6. Program Tracker
7. Source Registry
8. Governance
9. Build Status

## Home Page

The home page should explain what the OS is and provide one clear button:

Open Teacher Dashboard

## Teacher Dashboard Page

This page links to the Google Sheet MVP or future Apps Script dashboard.

## Course Spine Page

This page lists the courses:

- DC Theory
- Conduit Bending
- Wire Applications
- Code and Practices
- OSHA-10hr
- Print Reading
- Studio 5000 / Emulate 3D

It also lists the patched-in fundamentals:

- Leadership
- Motors
- AC Theory

## Assignment Builder Page

This page explains the assignment workflow:

Course -> Topic -> Skill -> Lenses -> Draft -> Teacher Review -> Ready

## Review Queue Page

This page explains where draft assignments are reviewed.

## Program Tracker Page

This page explains how the instructor sees what exists, what is ready, and what needs work.

## Source Registry Page

This page explains how source materials are cataloged before use.

## Build Status Page

This page shows the current vertical slice and next build actions.

## Build Rule

Do not overdesign the first site.

The first site should be a clean front door, not a full LMS.

## End-User Test

The instructor should be able to reach the Google Sheet MVP in one click.
